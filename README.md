# Connect Live 🚀

Connect Live is a real-time communication platform that enables users to connect instantly through live chat, video calls, or collaboration sessions.

The goal of this project is to provide a seamless and interactive environment where users can communicate, collaborate, and share information in real time.

## ⚙️ Installation

Follow these steps to run the project locally.

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/devabokare/connect-live.git
cd connect-live


2️⃣ Install Dependencies
npm install

or

cd client
npm install
3️⃣ Setup Environment Variables

Create .env file:

PORT=5000
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
4️⃣ Run the Project

Backend

npm run server

Frontend

npm start
